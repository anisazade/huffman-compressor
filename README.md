# Huffman File Compressor

A Python application that compresses and decompresses files using the Huffman coding algorithm. 
The project includes a graphical user interface built with Tkinter. Make sure you have it installed on Linux.

> `compress.py` is the application's entry point.

## Features

* Compress files (separetly or in group) using Huffman coding
* Decompress previously compressed files
* Simple graphical user interface
* Lossless compression

## About

This project was developed as part of a university course to demonstrate the implementation of the Huffman coding algorithm for lossless data compression.
